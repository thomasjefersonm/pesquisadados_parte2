Contextualização do Trabalho

Trabalho 2 da disciplina Engenharia de Dados (Engenharia de Software – 5ª fase – SATC), professor Jorge Luiz da Silva. É um complemento do trabalho 1 (Delta Lake e Apache Iceberg), em repositório separado.

Objetivo

Construir um pipeline que extrai os dados de um banco relacional (SQL Server), grava em um object storage (MinIO) e converte para o formato Delta Lake, repetindo depois os comandos INSERT, UPDATE e DELETE do trabalho 1.

Cenário e conjunto de dados

Mesma loja virtual fictícia do trabalho 1, agora hospedada em um banco SQL Server (LojaDB). Os dados foram criados pelo grupo e estão em data/:

Arquivo Conteúdo
data/clientes.csv 4 clientes
data/pedidos.csv 5 pedidos

Modelo ER

Um cliente possui vários pedidos (relação 1:N por id_cliente).

DDL (SQL Server)

CREATE TABLE clientes (
    id_cliente INT PRIMARY KEY,
    nome       NVARCHAR(100) NOT NULL,
    cidade     NVARCHAR(100),
    uf         CHAR(2)
);

CREATE TABLE pedidos (
    id_pedido      INT PRIMARY KEY,
    id_cliente     INT NOT NULL,
    produto        NVARCHAR(100) NOT NULL,
    quantidade     INT NOT NULL,
    valor_unitario DECIMAL(10,2) NOT NULL,
    data_pedido    DATE NOT NULL,
    status         NVARCHAR(20) NOT NULL,
    CONSTRAINT fk_pedidos_clientes
        FOREIGN KEY (id_cliente) REFERENCES clientes (id_cliente)
);

Arquitetura

SQL Server (LojaDB)  ──▶  MinIO: landing-zone/ (CSV)  ──▶  MinIO: bronze/ (Delta Lake)

Ferramentas utilizadas

Ferramenta Uso
SQL Server 2025 (Developer) Banco relacional de origem
MinIO Object storage compatível com S3
Docker Compose Sobe o SQL Server e o MinIO
PySpark 3.5.3 Processamento
delta-spark 3.2.1 Delta Lake
pyodbc + ODBC Driver 18 Conexão Python → SQL Server
boto3 Acesso ao MinIO (buckets e objetos)
UV Gerenciador de pacotes e ambiente virtual
